# カツオ UI 整理案(v0.6.1 → 次版)

LT 向けに仕様を棚卸しし、UI を組み直すための土台。エンジン側は触らない。
モックは `mock/index.html`(ブラウザで直接開ける。ビルド不要)。

## 1. 現状の画面(v0.6.1、1 画面縦スクロール)

上から順に:

| # | ブロック | 中身 |
|---|---|---|
| 1 | ヘッダ | ブランド名、状態ピル(停止中/同期中/動作中)、往復遅延、使い方 3 行 |
| 2 | なめらかさプリセット | 20 / 50 / 100 / 200 ms |
| 3 | 音の高さ | L の大数字(タップで数値入力)、−/+、太いスライダ、ジャンプ行(最小/0/既定/最大)、P1〜P3、R(左右別々 ON 時)、刻み幅、左右を別々に設定 |
| 4 | 処理方式(マイク) | 低遅延 / PV 55 / PV 110 |
| 5 | 音量 | −6〜+12 dB |
| 6 | 音源 | マイク音量、他アプリの音を拾う(+音量+状態)、処理方式(捕獲)、原音の抑え込み、出力先、入力元 |
| 7 | 詳細設定(折りたたみ) | 原音まぜ、なめらかさ(スライダ)、走査幅、マイクの前処理、出力用途(実験)、ユーザー補助系統の音量、テーマ |
| 8 | 末尾 | 遅延表示の説明、注意事項 5 行、診断行、10 秒録音 |
| 9 | 固定フッタ | 開始 / 停止 |

### 使いづらさの原因(仮説)

- **18 項目が 1 本の縦スクロールに並ぶ。** 毎日触るのは「音の高さ」「音量」「開始」だけなのに、そこへ辿り着くまでに他が目に入る。
- **同じ概念が 2 か所にある。** 「なめらかさ」はプリセット(#2)とスライダ(#7)に分かれている。
- **捕獲(他アプリの音)に関する項目が散らばっている。** 処理方式(捕獲)・原音の抑え込み・出力用途・ユーザー補助音量は全部「他アプリの音を拾う」の付属なのに、#6 と #7 に分散。
- **再起動が要る設定とそうでない設定の区別が画面にない。** 出力先/入力元/出力用途/走査幅/前処理は変えると Service 再起動(捕獲 ON なら同意ダイアログ再表示)。
- **使う環境(有線 USB / Bluetooth / 実験)ごとに設定の組み合わせが違う**のに、毎回手で切り替えている。→ ユーザー要望「デバイス別プロファイル」。

## 3. 整理案: 4 タブ + 常時表示の開始/停止

```
┌─────────────────────────────────┐
│ カツオ   [● 動作中 往復 6.2ms] [停止] │ ← 上部バー。どのタブでも開始/停止できる
├─────────────────────────────────┤
│                                 │
│         (タブの中身)             │
│                                 │
├─────────────────────────────────┤
│  聞く   音源   プロファイル  詳細  │ ← 下部タブバー
└─────────────────────────────────┘
```

### タブ 1「聞く」— 毎日触るものだけ

- 大数字 L(タップで数値入力)。左右別々 ON のときは L / R を横に 2 つ。
- −/+ ボタン、その間に刻み幅ピル(「1/8 音」タップで循環)。
- 太いスライダ(−1200〜+1200)。
- ジャンプ行: 最小 / 0 / 既定 −89 / 最大。
- P1 / P2 / P3(タップで呼び出し、長押しで登録)。
- 音量スライダ(−6〜+12 dB)。
- 停止中は先頭に「1. 有線イヤホン 2. 開始 3. 高さを合わせる」の 3 行。

### タブ 2「音源」— 何を聞くか、どこへ出すか

3 つのセクション。再起動が要る項目には **「再起動」バッジ** を付ける。

1. **マイク** — 音量(最小で OFF)、前処理 [再起動]、入力元 [再起動]、処理方式(折りたたみ「低遅延のままを推奨」)
2. **他アプリの音** — ON/OFF トグル。ON のときだけ以下が展開:
   音量、状態行(停止中/同意待ち/捕獲中/無音)、処理方式、
   **原音を消す方法**(ラジオ 3 択):
   - 何もしない(二重に聞こえる)
   - ダミー Bluetooth に原音を逃がす(手順リンク)
   - ユーザー補助系統に載せてメディア音量を絞る(実験)[再起動] → 選ぶと「原音の抑え込み %」と「ユーザー補助音量」が出る
3. **出力先** — 自動 / 一覧 [再起動]

### タブ 3「プロファイル」— 環境ごとの設定セット(新規)

- カード一覧。各カードは名前・対象デバイス・主な値の要約(シフト / 音源 / 出力先)。
  例: 「USB 有線・会話」「BT + USB・音楽(捕獲)」「実験: ユーザー補助」
- 「出力先デバイスが変わったら自動で切り替える」トグル。
- 「現在の設定をプロファイルとして保存」ボタン。
- プロファイルに含む項目: シフト L/R、音量、音源タブの全部、詳細の走査幅・なめらかさ。
  含めない: テーマ、P1〜P3(グローバル)。
- **未実装。** モックで形を決めてから実装する。実装コストは Params の保存/復元をまとめる程度。

### タブ 4「詳細」— 滅多に触らないもの

- なめらかさ(窓長): 4 段プリセット + スライダを 1 つのコントロールに統合。
- 原音まぜ(Dry/Wet)
- 走査幅(マイク経路)[再起動]
- テーマ
- 診断(経路 / xrun / コールバック時間)、10 秒録音
- 折りたたみ: 遅延表示の説明、注意事項、バージョン、コードネーム

## 4. 決めたいこと — 各案をモックで比較する

モックは URL パラメータ `d1`〜`d5` で案を切り替え、`?compare=d3` のように指定すると
A 案と B 案を左右に並べて表示する(ツールバーの「比較」ボタンから開ける)。

### D1. タブの数

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | 4 タブ(聞く / 音源 / プロファイル / 詳細) | プロファイルが一覧で見える。保存・編集の置き場所が明確 | タブが 1 つ増え、「聞く」からプロファイル切替に 2 タップ |
| B | 3 タブ(聞く / 音源 / 詳細)。プロファイルは「聞く」最上部の横スクロールチップ列(タップで適用、長押しで上書き保存、末尾に「+ 保存」) | 切替が 1 タップ。日常操作が「聞く」で完結 | 内容の確認・編集が窮屈。チップ長押しが発見されにくい |

### D2. 開始 / 停止の位置

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | 上部バー右のボタン。状態ピルと同じ行 | 状態と操作が同じ場所。画面下がタブバーだけで済む | 親指から遠い。ボタンが小さい |
| B | 下部タブバーの直上に幅いっぱいの固定ボタン(現状踏襲)。上部バーは状態ピルのみ | 親指に近く大きい。現状と同じ手癖 | 下部が 2 段になり中身の領域が減る |

### D3. 左右別々 ON のときの並び

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | 横 2 つ(L と R の大数字を横並び、下にスライダ 2 本) | 左右の差が一目で見える。縦に短い | 数字が小さくなる。−/+ がどちらの数字に効くか迷う |
| B | 縦 2 段(L ブロック → R ブロック。各ブロックに数字・−/+・スライダ) | 各耳の操作が完結し誤操作しにくい | 縦に長い。ジャンプ行・プリセットが下へ押される |

### D4. 「原音を消す方法」の見せ方

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | 3 択ラジオ(何もしない / ダミー Bluetooth に逃がす / ユーザー補助系統に載せて絞る)。選んだ方式に必要なスライダだけ展開 | 「何をするための設定か」が先に読める。使わない項目が隠れる | ラジオ 1 つに複数の内部設定(出力用途 + 抑え込み + 音量)が束ねられ、細かく触れない |
| B | 現状踏襲(「出力をユーザー補助の音量系統に載せる(実験)」トグル、「原音の抑え込み」スライダ、「ユーザー補助系統の音量」スライダを並べる。トグル OFF のときは抑え込みをグレーアウトしヒント表示) | 内部設定と 1:1 で対応し実装が薄い | 3 つの関係が読み取れない。ダミー Bluetooth 運用が画面に現れない |

### D5. プロファイルの中身と自動切替

| 案 | 内容 | 利点 | 欠点 |
|---|---|---|---|
| A | フルセット(シフト L/R・音量・音源タブ全部・走査幅・なめらかさ)+「出力先が変わったら自動で切り替える」トグル | 環境を替えたときの手作業がゼロになる | 自動切替で意図せず設定が変わる可能性。出力先検出のタイミングが再起動と絡む |
| B | フルセット、ただし自動切替なし。代わりに開始時に「いまの出力先は ◯◯。プロファイル ◯◯ を適用しますか」と確認 | 意図せず変わらない。実装が単純 | 毎回 1 タップ増える |

いずれもテーマ・P1〜P3 はプロファイルに含めない(グローバル)。

## 5. 決定(2026-09-19)

D1=A(4 タブ)、D2=A(開始/停止は上部バー)、D3=A(左右別々は横 2 つ)、
D4=B(原音を消す方法は現状踏襲: トグル + スライダ 2 本)、D5=A(プロファイルはフルセット + 出力先連動の自動切替)。

追加要望: **上部バーに適用中のプロファイルを表示する。** 各プロファイルに 1〜2 文字の略称を持たせ、
上部バーの「カツオ」の横に略称ピルとして出す(例: `U会` = USB 有線・会話)。ピルをタップするとプロファイルタブへ移動。
どのプロファイルも適用していない(手で変えて一致しなくなった)ときはピルを「—」にする。

この構成でモックの反復を打ち切り、Android 本体に実装する(v0.7.0)。
