# パフォーマンス要件 — u3-web-demo

| ID | 要件 | 目標値 | 測定 | Source |
|---|---|---|---|---|
| PR-1 | レンダ量子内処理 | 128 サンプル分の WASM 処理がレンダ量子時間(128/fs ≈ 2.7ms @48k)の 50% 以内 | デモ動作中のグリッチ有無(聴感)+ B2 の CPU 比から外挿 | NFR-1 [desc] |
| PR-2 | 往復遅延の可視化 | 目標値は設けない(デモの位置づけ)。実測内訳を 1 秒ごとに表示 | US1.4 の遅延表示 | feasibility Q3 |
| PR-3 | UI 応答 | スライダー操作から音の変化開始まで知覚遅延なし(postMessage は次レンダ量子で反映 ≈ 3ms + 平滑 20ms) | 聴感確認 | US1.2 |
| PR-4 | 起動時間 | ページロード→開始可能まで 2 秒以内(WASM は SINGLE_FILE 内包で追加フェッチなし) | 目視 | 機能設計 Q1 |
| PR-5 | ページ重量 | 生成物合計 500KB 以下(コアは小さく、SINGLE_FILE の base64 増を含めても十分) | ビルド出力サイズ | SR-2.1 |

レンダ量子ごとのヒープ確保ゼロ(HEAPF32 固定領域)により GC 起因のグリッチを構造的に回避する(契約 2)。
